# Scape Image Drop

Public phone companion for a Scape X Mobile exhibition demo. Scan the QR code displayed by the table to join its session. Wi-Fi and mobile data are supported.

Only the phone webpage, browser bundle, sample image, and third-party notices are published here. The Unity project and local installation service are maintained separately.

GitHub Pages: https://usmanarif24.github.io/scape-image-drop/
