# ONE MENA · Interactive Table Demo

ONE Events & Experiences branded phone companion for the Scape X Mobile demo. Scan the table QR to join. Wi-Fi and mobile data are supported.

Preview: https://usmanarif24.github.io/scape-image-drop/one-mena/

The Unity project and local relay stay private. This folder contains only public phone assets.

Logo source: https://www.one-mena.com/ (official white logo, retained unchanged). Brand colours and Montserrat typography follow the referenced site. Montserrat is licensed under the SIL Open Font License; see assets/OFL.txt. Bundled JavaScript notices are in THIRD_PARTY_NOTICES.txt.
